Checking the server connection…

  1. Your fictional profile goes to the registration server.
  2. The server authenticates to Identity Lens. Its secret never reaches this page.
  3. Identity Lens saves the record and any supplied session, then calculates the assessment.
  4. Your analyst opens Investigations and Refresh to inspect it.
